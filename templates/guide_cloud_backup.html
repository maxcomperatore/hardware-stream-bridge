Vintage Synth Cloud Backup & SysEx Librarian

Cloud backup for synthesizers used to mean desktop drivers, MIDI-OX buffer tuning, and folders of unnamed .syx files. In 2026, a browser-native SysEx librarian can back up DX7 patches, save Juno-106 presets, and sync your vault — without installing software.

What is a SysEx librarian?

A SysEx librarian captures, stores, and restores synthesizer presets. For decades, doing this meant installing drivers, adjusting MIDI-OX buffer size, and sorting folders of raw, unnamed .syx files.

I built bipluk because I wanted to back up my DX7 and Juno-106 without dealing with legacy desktop apps. It runs in the browser, uses Web MIDI, and saves everything to a secure cloud vault.

Remember this

Zero-install web utilities are not a compromise—they are a feature. Most synth owners only back up their sounds twice a year. Downloading desktop software for a five-minute task is a waste of time.

Universal cloud backups

If you tour with vintage synths, run a commercial studio, or just want to protect your patches from dead internal batteries, local backups aren't enough. You need off-site storage.

My cloud library saves your soundbanks privately.

  • Raw exports: You can download your standard .syx files anytime. No lock-in.
  • Paced sending: The app handles Web MIDI output timing so you don't overflow vintage microprocessor buffers.
  • Searchable vault: Name your patches, search them, and organize soundbanks online.

Back up your DX7 (no desktop apps)

The Yamaha DX7 is the classic entry point. To back it up: disable memory protect, enable SysEx channel 1, and request the dump directly from the web interface. No TX7 editors or legacy setups.

Save your Juno-106 patches

A Roland Juno-106 stores 128 presets in battery-backed RAM. When the internal CR2032 battery dies, those presets disappear forever.

You cannot request a dump remotely on the Juno-106. You have to set the rear function switch to 'III' (enable SysEx) and physically press 'WRITE' on the panel to stream the patches.

The desktop alternatives are dead

Windows users still run MIDI-OX—a 32-bit utility last updated in 2010. Mac users rely on Snoize. Neither offers cloud sync, and both require platform-specific installation.

By running in Chrome or Edge, bipluk works on Mac, Windows, Linux, and Chromebooks out of the box.
