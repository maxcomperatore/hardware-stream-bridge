ADA & WCAG 2.1 AA Compliance

Accessibility Statement

Last Updated: August 5, 2026

1. Our Commitment

bipluk is committed to ensuring digital accessibility for all users, including people with disabilities. We are continually improving the user experience for everyone, applying relevant accessibility standards, and ensuring our browser-native Web MIDI librarian interface complies with the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA standards.

2. Measures to Support Accessibility

To ensure accessibility across the bipluk web application, we implement the following practices:

  • Integrate accessibility best practices into all frontend component design and development.
  • Ensure full keyboard navigability across editor controls, patch vaults, and interactive elements.
  • Maintain high contrast color ratios for maximum visual legibility.
  • Implement semantic HTML5 structural tags and WAI-ARIA attributes for assistive screen readers (NVDA, JAWS, VoiceOver).
  • Conduct regular automated testing and manual keyboard audit reviews.

3. Conformance Status

The Web Content Accessibility Guidelines (WCAG) defines requirements for designers and developers to improve accessibility for people with disabilities. It defines three levels of conformance: Level A, Level AA, and Level AAA.

Conformance Designation

bipluk is fully conformant with WCAG 2.1 Level AA. Fully conformant means that site features and browser-native SysEx interfaces conform to accessibility standards without exception on supported modern browsers.

4. Technical Specifications

Accessibility of bipluk relies on the following core web technologies to operate with web browsers, screen readers, and assistive devices:

HTML5 & WAI-ARIA
Vanilla CSS3
JavaScript (Web MIDI)
SVG Icons
