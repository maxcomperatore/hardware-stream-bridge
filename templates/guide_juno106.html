How to Save and Backup Juno-106 Presets

The Roland Juno-106 is a 1984 analog synthesizer. It contains 128 patch memories powered by a CR2032 battery. Unlike modern MIDI hardware, the Juno-106 does not support dump request commands over MIDI. You cannot pull patches from the machine remotely; you must initiate the stream physically from the front panel. This guide shows you how to configure the rear switches to allow SysEx transmission and how to stream your memory banks to the browser.

Hardware Setup Steps

  • Step 1: Locate the Protect Switch on the back of the Juno-106 next to the patch shift jack. Flip it to OFF.
  • Step 2: Locate the MIDI Function Switch on the rear panel.
  • Step 3: Ensure it is switched to III (Keyboard, controllers, and System Exclusive data). If it is set to I or II, Web MIDI backups will fail silently.
  • Step 4: Set your MIDI receive channel to match the app (typically Channel 1).

Remember this

If the rear-panel MIDI function switch is set to position I or II, the Juno-106 filters out all System Exclusive data. It must be set to position III to enable patch dumps.
